# Mudit Dholakia — tableau portfolio

## Project purpose

An original synthetic-sales dashboard blueprint and Tableau Embedding API v3 example.

## Engineering decisions

- Use synthetic inputs so demonstrations can be shared publicly.
- Separate credentials and environment configuration from source control.
- Prefer supported APIs and explicit manual deployment for learning environments.
- Validate inputs before mutations and use minimum required permissions.
- Distinguish local validation from cloud integration evidence.

## Demonstration checklist

1. Explain the architecture in README.md and the boundaries of the example.
2. Run the local example and inspect its output.
3. Configure a dedicated development environment using the documented prerequisites.
4. Record cloud validation results and screenshots containing synthetic data only.
5. Explain an operational failure, its diagnosis, and the mitigation.
